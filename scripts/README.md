# Clash Meta / Mihomo 脚本

将 [main.js](main.js) 的全部内容复制到客户端的脚本编辑器，保存后更新一次订阅。脚本使用客户端提供的 `main(config)` 入口，以 `config/Full.ini` 为蓝本生成策略组与规则。

脚本会过滤公告、流量余量等节点，给没有国旗的节点补国旗；补国旗后如有同名节点，会给后续节点添加编号。随后创建起飞、AI、微软、低延迟、负载均衡、地区、广告和兜底策略组。原 INI 中的 15 个远程规则列表改为 Mihomo `rule-providers`，保留原有规则顺序；列表每 24 小时更新一次。原有 `rules` 将被替换，节点、代理来源以及其余客户端配置会保留。

`rename_node=!!GROUPID=...` 使用的是订阅转换器的来源编号。脚本收到的 `config.proxies` 通常没有该编号，因此无法可靠地为“大讯”“龙猫”自动加来源前缀；如果需要区分多个机场，请在客户端的订阅或代理提供者设置中添加前缀。使用 `proxy-providers` 时，节点会通过策略组动态引用，脚本也无法直接改写提供者内部的节点名称。代理提供者中的地区组可能没有匹配节点，此时该地区组回落到 `REJECT`；US-AI 组默认使用“起飞”，微软组默认直连（`DIRECT`），两者均可手动切换到有节点的地区。

规则文件使用仓库的 GitHub Raw 地址。首次下载规则需要网络；如客户端不支持 `format: text` 的规则提供者，请更新其 Mihomo 内核。
